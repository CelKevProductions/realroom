# Contrôles

- `unitaires.txt` : 240 tests, dont les dix nouveaux contrôles des repères.
- `parser.txt` : rôle principal, dimensions, quaternions et rejet des emprises hors contour.
- `api.txt` : 19 scénarios avec fournisseur simulé et PGlite local ; repli des repères transmis au serveur.
- `build-tests.txt` : compilation utilisée par les tests API.
- `rendus.txt` : figures de contrôle des deux séjours.
- Les données agrégées sont sous `../analyse.json` et `../comparaison.json` ; les scènes complètes restent sous `.data/`.
